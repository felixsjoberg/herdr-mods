# Vantage

Full Herdr App layout combining **Aura Soft Dark**, a glass pill top bar (`vantage-tabs`), repo-grouped **Spaces** (`vantage-spaces`), and **Agents** with Claude Code-style GitHub PR badges (`vantage-agents`).

```text
Read ~/.config/herdr-app/AGENTS.md, then add this layout: https://github.com/felixsjoberg/herdr-mods/tree/main/vantage
```

See [RECIPE.md](RECIPE.md) for full details and what programs the mods invoke.
